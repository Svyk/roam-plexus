# Batch 1 (0.16.0)

Ships UX-5, UX-12, PERF-2, and DATA-4.

Measured on drawing ITvT3bqaL. Theme does not write while the editor is open. A minimize click restores the stored theme and keeps edit time. A fit rewrote the camera on close, so fit is not called. Lock actions exist. extension.version was 0.15.0.

Theme-follow defaults on. Lock, unlock, and Copy diagnostics are command-list entries. Generation is localStorage plexus-generation and stays on a second load of the same version. Crop keys gain nN| only when N is above 0.

Cut: grid color, default font, presenter on open, and fit on open. Palette stays two commands.
