# Batch 2 (0.17.0)

Ships REF-14, REF-5, and REF-10.

Readwisenotes has two regions containers and 12 children. Horizontal outline children are min-width 200px and scroll. A 280px crop is wider, so the gallery is a wrapping grid.

REF-5: size, alignment, bare, and padding on the existing per-ref override. The card uses them.

REF-10: a chooser when the selection has more than one kind. The pick creates that kind. Palette stays two commands.
